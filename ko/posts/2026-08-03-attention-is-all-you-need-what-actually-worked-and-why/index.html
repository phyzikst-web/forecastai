Attention Is All You Need 논문 리뷰: 무엇이 실제로 작동했고 왜 중요했는가

데이터과학
인공지능
LLM

인공지능 역사의 전환점이 된 논문 “Attention Is All You Need”(Vaswani et al., 2017)을 심층 분석합니다. 셀프 어텐션의 핵심 수학적 원리, 설계적 선택(Scaling, Pre-LN vs Post-LN), 그리고 왜 트랜스포머가 기존 순환 신경망(RNN)을 완벽하게 대체했는지 비판적으로 검토합니다.

저자

Prof. Shin

공개

2026-08-03

2017년 Vaswani 등이 발표한 Attention Is All You Need 논문은 현대 인공지능 분야에서 가장 큰 변곡점 중 하나로 평가받고 있습니다. 이 논문은 기존 시퀀스 데이터 처리를 지배하던 순환(Recurrence) 구조와 합성곱(Convolution)을 완전히 배제하고, 오직 셀프 어텐션(Self-Attention) 메커니즘만을 사용하는 트랜스포머(Transformer) 아키텍처를 도입했습니다. 오늘날 GPT-4, Gemini, Claude, Llama 등 현존하는 거의 모든 거대 언어 모델(LLM)이 바로 이 아키텍처의 직계 후손들입니다.

원래는 기계 번역 태스크를 위해 설계된 모델이었지만, 트랜스포머의 핵심 설계 원리는 자연어 처리를 넘어 컴퓨터 비전, 시계열 분석, 단백질 구조 예측 등 거의 모든 딥러닝 도메인으로 확장되었습니다. 이번 포스트에서는 트랜스포머의 핵심 수학적 구조와 구현 디테일을 세밀히 뜯어보며, 이 패러다임 전환이 어떻게 성능과 확장성을 동시에 확보할 수 있었는지 분석하겠습니다.

패러다임의 전환: 순환(Recurrence)의 한계와 극복

트랜스포머 이전의 시퀀스 변환 모델은 RNN(Recurrent Neural Network), LSTM, GRU 등 순환 구조 신경망이 주도하고 있었습니다. 이러한 RNN 계열 모델들은 이론적으로 임의의 길이를 갖는 시퀀스를 처리할 수 있지만, 다음과 같은 두 가지 치명적인 한계를 안고 있었습니다.

  1. 병렬 연산의 병목 (Sequential Computation Bottleneck): RNN은 시점 \(t\)에서의 은닉 상태(Hidden State) \(h_t\)를 계산할 때, 직전 시점의 \(h_{t-1}\)과 현재 시점의 입력 \(x_t\)를 함수로 전달받아야 합니다. 이 순차적 종속성은 GPU와 같은 병렬 하드웨어 가속기를 100% 활용하는 학습을 방해합니다. 즉, 앞의 연산이 끝날 때까지 뒤의 연산을 시작할 수 없습니다.
  2. 기억력 상실과 기울기 소실 (Vanishing Gradient): 긴 시퀀스를 처리할 때, 초기 토큰의 정보는 무수히 많은 전이 가중치를 곱하는 과정에서 기하급수적으로 희석됩니다. 첫 토큰과 \(N\)번째 토큰 사이의 최단 경로 길이가 \(O(N)\)이기 때문입니다.

트랜스포머는 순환 구조를 완전히 없애고 셀프 어텐션(Self-Attention)으로 이를 해결했습니다. 시퀀스 안의 모든 토큰 정보를 단 한 번의 연산으로 직접 비교할 수 있게 만듦으로써, 토큰 간의 최단 경로 길이를 \(O(1)\)로 줄였고, 모든 토큰을 병렬로 한 번에 처리하여 대규모 연산이 가능해졌습니다.

셀프 어텐션의 수학적 기초

트랜스포머 아키텍처의 중추는 셀프 어텐션으로, 이는 입력 토큰 시퀀스 내에서 쿼리(Query) 벡터와 키(Key) 벡터의 유사도를 구한 뒤, 이를 확률 분포로 변환하여 밸류(Value) 벡터들의 가중합을 계산하는 메커니즘입니다.

스케일드 닷 프로덕트 어텐션 (Scaled Dot-Product Attention)

길이가 \(S\)인 입력 토큰 시퀀스의 표상 행렬 \(H \in \mathbb{R}^{S \times d_{model}}\)이 주어졌을 때, 세 개의 학습 가능한 가중치 행렬 \(W_Q, W_K, W_V \in \mathbb{R}^{d_{model} \times d_k}\)를 이용해 세 가지 행렬을 사영합니다.

\[Q = H W_Q, \quad K = H W_K, \quad V = H W_V\]

어텐션 연산 수식은 다음과 같이 정의됩니다.

\[\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V\]

이 공식에 숨겨진 직관적인 원리는 다음과 같습니다. * 내적 연산 (\(Q K^T\)): 두 벡터의 내적은 유사도를 뜻합니다. 쿼리 \(q_i\)와 키 \(k_j\)의 내적은 토큰 \(i\)가 토큰 \(j\)에 대해 가져야 할 원시적 관심의 크기를 나타냅니다. * 스케일링 인자 (\(1/\sqrt{d_k}\)): 이 장치는 트랜스포머 학습의 안정성에 매우 핵심적입니다. 차원 수 \(d_k\)가 커질수록 내적 결과의 분산도 비례하여 커집니다. 내적 값이 너무 크거나 작아지면 소프트맥스 함수가 극단적인 확률(0 또는 1) 근처로 몰리며 미분 값이 거의 0에 수렴하는 기울기 포화 현상(Gradient Saturation)이 생깁니다. 이를 방지하기 위해 \(\sqrt{d_k}\)로 나누어 내적 분포의 분산을 1로 보정해 줍니다.

멀티헤드 어텐션 (Multi-Head Attention)

단일 차원 공간에서만 어텐션을 수행하면, 특정 정보에만 가중치가 편향되어 전체적인 맥락을 놓치기 쉽습니다. 트랜스포머는 전체 차원 \(d_{model}\)을 헤드 개수 \(h\)개로 쪼개어 각각 \(d_k = d_{model} / h\) 차원의 부분 공간들에서 병렬로 어텐션을 수행합니다.

\[\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \dots, \text{head}_h) W^O\]

\[\text{where} \quad \text{head}_i = \text{Attention}(Q W_i^Q, K W_i^K, V W_i^V)\]

이 구조 덕분에 한 헤드는 주어와 동사의 관계(문법 정보)에 집중하고, 다른 헤드는 지시대명사가 가리키는 대상을 찾는 등, 모델이 동일 시퀀스 내에서 여러 상이한 관점의 특징을 동시에 포착할 수 있게 됩니다.

PyTorch 셀프 어텐션 구현

다음은 PyTorch를 사용하여 어텐션 메커니즘을 처음부터 구현한 코드입니다. 각 단계에서 데이터의 텐서 차원 변화를 확인하기 위해 단언문(assert) 및 크기 출력을 덧붙였습니다.

코드 
import math
import torch
import torch.nn as nn

class ScaledDotProductAttention(nn.Module):
    def __init__(self, d_k: int):
        super().__init__()
        self.d_k = d_k
        self.softmax = nn.Softmax(dim=-1)
        
    def forward(self, q: torch.Tensor, k: torch.Tensor, v: torch.Tensor, mask: torch.Tensor = None):
        # 입력 텐서 차원: [Batch, Head, SeqLen, d_k]
        batch_size, num_heads, seq_len, d_k = q.shape
        
        # 1. 유사도(Attention Score) 계산: [Batch, Head, SeqLen, SeqLen]
        scores = torch.matmul(q, k.transpose(-2, -1)) / math.sqrt(self.d_k)
        
        # 2. 마스킹 처리 (패딩 토큰 또는 디코더의 미래 정보 차단)
        if mask is not None:
            scores = scores.masked_fill(mask == 0, -1e9)
            
        # 3. 소프트맥스를 통과시켜 확률 가중치 생성
        attn_weights = self.softmax(scores)
        
        # 4. 가중치를 반영한 밸류의 가중합 도출: [Batch, Head, SeqLen, d_k]
        output = torch.matmul(attn_weights, v)
        return output, attn_weights

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model: int, h: int):
        super().__init__()
        assert d_model % h == 0, "d_model은 헤드 개수 h로 나누어 떨어져야 합니다."
        self.d_model = d_model
        self.h = h
        self.d_k = d_model // h
        
        # 개별 선형 변환 레이어
        self.w_q = nn.Linear(d_model, d_model)
        self.w_k = nn.Linear(d_model, d_model)
        self.w_v = nn.Linear(d_model, d_model)
        self.w_o = nn.Linear(d_model, d_model)
        
        self.attention = ScaledDotProductAttention(self.d_k)
        
    def forward(self, q: torch.Tensor, k: torch.Tensor, v: torch.Tensor, mask: torch.Tensor = None):
        batch_size = q.size(0)
        
        # 사영 및 헤드 쪼개기: [Batch, SeqLen, d_model] -> [Batch, SeqLen, h, d_k] -> [Batch, h, SeqLen, d_k]
        q_proj = self.w_q(q).view(batch_size, -1, self.h, self.d_k).transpose(1, 2)
        k_proj = self.w_k(k).view(batch_size, -1, self.h, self.d_k).transpose(1, 2)
        v_proj = self.w_v(v).view(batch_size, -1, self.h, self.d_k).transpose(1, 2)
        
        # 스케일드 닷 프로덕트 어텐션 수행
        out, attn_weights = self.attention(q_proj, k_proj, v_proj, mask)
        
        # 헤드 병합 및 원본 차원 회복: [Batch, h, SeqLen, d_k] -> [Batch, SeqLen, h, d_k] -> [Batch, SeqLen, d_model]
        out = out.transpose(1, 2).contiguous().view(batch_size, -1, self.d_model)
        return self.w_o(out), attn_weights

# 더미 데이터를 사용하여 텐서 연산 차원 변화 검증
B, S, d_model, h = 4, 10, 64, 8
mha = MultiHeadAttention(d_model, h)
dummy_x = torch.randn(B, S, d_model)
output, weights = mha(dummy_x, dummy_x, dummy_x)

print(f"입력 텐서 크기:  {dummy_x.shape}")
print(f"출력 텐서 크기:  {output.shape}")
print(f"어텐션 가중치 크기: {weights.shape}")
입력 텐서 크기:  torch.Size([4, 10, 64])
출력 텐서 크기:  torch.Size([4, 10, 64])
어텐션 가중치 크기: torch.Size([4, 8, 10, 10])

아키텍처 성패를 가른 핵심적인 세부 구조

어텐션 메커니즘이 가장 많이 주목을 받지만, 트랜스포머의 실질적인 최적화와 안정적인 작동에는 다른 핵심 장치들이 중요한 기여를 했습니다.

위치 인코딩 (Positional Encoding)

셀프 어텐션 수식은 순서 정보가 없는 집합 연산과 다름없습니다. 어텐션 행렬 내부에서 어떤 순서로 토큰을 넣든 결과는 동일하게 나타납니다. 즉, “개가 사람을 물었다”와 “사람이 개를 물었다”의 차이를 구분하지 못합니다.

이를 보정하기 위해 Vaswani 등은 토큰 임베딩 단계에 물리적인 신호 형태의 위치 정보(Positional Encoding)를 더해 줍니다.

\[PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i/d_{model}}}\right), \quad PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i/d_{model}}}\right)\]

주기가 각기 다른 삼각함수의 결합 벡터를 입력에 더함으로써, 모델은 순차적 처리 없이도 두 토큰이 얼마나 상대적으로 가깝고 멀리 있는지 인식할 수 있는 선형적인 기하학 특징을 확보하게 됩니다.

레이어 정규화 순서의 재구성: Post-LN vs. Pre-LN

오리지널 논문에서 활용된 정규화 순서는 레이어 통과 후에 정규화가 들어가는 Post-LN 방식이었습니다.

\[\text{Post-LN 블록: } \quad x_{l+1} = \text{LayerNorm}(x_l + \text{SubLayer}(x_l))\]

하지만 이 방식은 레이어의 층수가 수십 개 수준으로 깊어질 때, 역전파 과정에서 초기 레이어로 갈수록 기울기가 소실되거나 폭발하여 매우 세심한 학습률 Warmup 스케줄링 없이는 초기 수렴이 어렵다는 단점이 발견되었습니다. 따라서 현재의 거의 모든 대형 트랜스포머는 정규화를 통과한 뒤 잔차 연결을 진행하는 Pre-LN 방식을 채택합니다.

\[\text{Pre-LN 블록: } \quad x_{l+1} = x_l + \text{SubLayer}(\text{LayerNorm}(x_l))\]

Pre-LN 구조를 사용하면 정상적으로 역전파되는 통로(Shortcut)가 정규화의 크기 왜곡 없이 직접 끝단까지 연결되므로, 그레이디언트가 소실되지 않고 백개 이상의 레이어로 깊게 구성된 딥러닝 아키텍처도 무난하게 고속으로 수렴시킬 수 있게 되었습니다.

트랜스포머가 확장(Scaling)에 강한 이유

트랜스포머가 현대 신경망의 표준 모델로 우뚝 선 가장 핵심적인 강점은 ‘스케일링 효율성(Scaling Efficiency)’에 있습니다.

  • 최적 병렬화 가능성: 순차적인 의존 고리가 없으므로, 학습 과정에서 수만 개의 토큰 연산을 완벽히 큰 행렬 연산 하나로 처리해 GPU 하드웨어를 극한으로 사용할 수 있습니다.
  • 낮은 귀납적 편향 (Inductive Bias): RNN은 정보가 한 방향으로만 순차적으로 전이된다고 가정하며, CNN은 가까운 영역끼리 국소적 상관관계를 가진다고 가정합니다. 반면, 트랜스포머는 데이터의 가정을 최소화하므로, 충분히 크고 다양한 데이터만 공급된다면 고유의 내재된 구조를 스스로 고차원적으로 포착하는 잠재력을 보여 줍니다.

오리지널 트랜스포머 아키텍처의 한계

막강한 성능에도 불구하고 오리지널 아키텍처는 다음과 같은 기술적 한계를 여전히 극복하지 못하고 있습니다.

  1. 길이 제곱에 비례하는 연산 복잡도 (\(O(S^2)\)): 입력 쿼리와 키의 유사도 매트릭스를 직접 계산하는 과정 때문에 메모리와 연산 사용량이 시퀀스 길이 \(S\)의 제곱으로 팽창합니다. 이는 텍스트나 데이터를 장기 컨텍스트로 길게 입력하여 실행하려 할 때 엄청난 연산 장벽으로 작용합니다.
  2. 외삽의 불가능성: 학습 시 지정했던 최대 길이 위치 임베딩 정보의 범위를 넘어서는 입력 데이터가 시점에 들어올 경우, 절대적 위치 값이 정해져 있어 길이를 확장하여 추론하기 어렵습니다. (최근에는 이 한계를 극복하고자 RoPE, ALiBi 등의 상대적 보정 임베딩이 많이 보편화되었습니다.)
